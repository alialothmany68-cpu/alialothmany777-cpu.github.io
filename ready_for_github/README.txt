# تعليمات تشغيل الموقع على GitHub Pages مباشرة

تم تجهيز جميع الملفات الجاهزة للتشغيل الفوري داخل مجلد:
📁 **`ready_for_github`** (أو مجلد `dist`)

---

### الطريقة السريعة جداً (سحب وإفلات في GitHub بالمتصفح دون أي أوامر):

1. افتح مستودعك (Repository) على موقع **GitHub**.
2. ادخل داخل مجلد **`ready_for_github`** هنا على جهازك أو قم بتنزيله.
3. انسخ جميع الملفات الموجودة **داخل** `ready_for_github` (وهي: `index.html` ومجلد `assets` وباقي الأيقونات).
4. في صفحة مستودع GitHub، اضغط على **Add file** ثم **Upload files**.
5. اسحب الملفات وضعها مباشرة واضغط **Commit changes**.
6. اذهب إلى **Settings** (الإعدادات) في المستودع > ثم **Pages** من القائمة اليسرى.
7. تأكد أن:
   - **Source**: `Deploy from a branch`
   - **Branch**: اختر `main` (أو `master`) والمجلد `/ (root)`.
   - اضغط **Save**.
8. انتظر دقيقة واحدة وافتح الرابط، وسيعمل التطبيق فوراً بدون صفحة بيضاء!
